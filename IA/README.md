# IA — Continuité de travail NRP

Ce dossier est une **mémoire de projet versionnée et consultable**, pas une sauvegarde automatique des conversations ni des raisonnements internes de l'IA.

## Règles de reprise
1. Lire `Projet/README.md`, puis `IA/ETAT.md` et `IA/DECISIONS.md`.
2. Vérifier le contenu réel de Git avant toute modification ; ne pas écraser une évolution existante.
3. Distinguer **confirmé**, **hypothèse**, **mesuré**, **rejeté**, **à vérifier**.
4. Documenter chaque changement significatif avec date, source et raison.
5. Préserver la compatibilité entre langage NRP, firmware, matériel et applications.
6. Aucune publication de clés, informations personnelles ou notes privées dans ce dépôt public.

## Limite
La continuité nécessite de consulter le dépôt dans les futures sessions. Git ne mémorise pas automatiquement des informations absentes des fichiers.
